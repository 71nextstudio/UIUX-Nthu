# 介面視覺基礎（Unit 08）

把資訊架構轉譯成「看得懂、做得出來」的畫面。四個面向：版面、排版、色彩、一致性。

## V-L 版面配置

| 代碼 | 規則 | 標準 |
|---|---|---|
| V-L1 | 8pt Grid 間距 | 所有間距是 **8 的倍數**，微調用 4（Icon 與文字、標籤內距）。常用：4 微調、8 元件內最小、16 內距與手機邊距、24 群組之間、32 區塊之間、48 Section 之間。出現 13、27、9 這類數值就是違規。 |
| V-L2 | 親密性分組 | 內距 < 外距；組內約 6–8、組間約 24。先用距離分組，其次淺底色，最後才用框線。 |
| V-L3 | 響應式網格 | Desktop 12 欄、Mobile 4 欄＋16pt 左右邊距。元件寬度跟著欄數走，不寫死像素。 |
| V-L4 | 視覺動線 | 文字密集頁用 F 型（重要關鍵字放每行開頭）；行銷頁用 Z 型（左上 Logo → 右上導覽 → 主視覺 → 右下 CTA）。首屏要回答「這是什麼＋我能做什麼」。 |

**常見地雷**：害怕留白把資訊塞滿；間距隨意拉；過度使用框線與陰影區隔區塊（陰影只留給浮起來的元件）。

## V-T 排版與字體

| 代碼 | 規則 | 標準 |
|---|---|---|
| V-T1 | 字級階梯 | 內文基準：網頁 16px、資訊密集的 App 或後台 14px。全站字級 **≤ 5 種**。每一級定義「字級／行高／字重」並存成 Text Styles。參考：H1 32/40 Bold、H2 24/32 Semibold、H3 20/28 Semibold、Body 16/24 Regular、Caption 12/16 Regular。 |
| V-T2 | 層級靠大小與粗細 | 主次用字級＋字重拉開，顏色只做輔助。**轉成黑白後層級仍清楚**才算成功。 |
| V-T3 | 行高 | 內文 **1.4–1.6 倍**；標題 1.2–1.3 倍。 |
| V-T4 | 每行字數 | 中文約 **25–35 字**，英文約 45–75 字元；寬螢幕要設定文字區塊的 max-width。 |
| V-T5 | 中西文混排 | 中文 Noto Sans TC／PingFang TC 搭英文 Inter／SF Pro，x-height 與字重要接近。一個產品 **≤ 2 套字體**，裝飾字體只用在 Logo 或大標。 |
| V-T6 | 數字等寬 | 金額、數據、計時器使用 Tabular Figures（CSS：`font-variant-numeric: tabular-nums`），小數點要對齊。 |

**常見地雷**：靠換顏色做層級；內文行距過窄；使用過多裝飾性字體。

## V-C 色彩系統

| 代碼 | 規則 | 標準 |
|---|---|---|
| V-C1 | 60-30-10 | 60% 中性背景、30% 品牌主色與結構色、10% 強調色（只用在 CTA 與關鍵數據）。同時出現 3 個以上高飽和色搶焦點就違規。 |
| V-C2 | 語意化命名 | 依用途命名，不依外觀命名：`color-error` 而不是 `red`，`text-secondary` 而不是 `gray-500`。色票存成 Color Styles 或 Variables。Neutral 建議 5–9 階，狀態色 Success／Warning／Error／Info。 |
| V-C3 | WCAG 對比度 | 一般內文 **≥ 4.5:1（AA）**；大字（≥ 18pt，或 ≥ 14pt 粗體，約 24px／18.66px bold）**≥ 3:1**。黃色、淺灰最容易不及格。一律用 `scripts/contrast.py` 計算。 |
| V-C4 | 避免純黑純白 | 純黑 #000 配純白 #FFF（21:1）長時間閱讀會眩光。文字建議用深灰（如 #1D1D1F），背景用近白（如 #FBFBFD）。 |
| V-C5 | 不只靠顏色 | 狀態必須搭配 Icon 或文字（例如「✕ 密碼至少 8 個字元」），色盲使用者才分得出來。 |

## V-S 一致性與規範

| 代碼 | 規則 | 標準 |
|---|---|---|
| V-S1 | 視覺一致 | 圓角只用 2–3 種（例如小元件 4、卡片 12、膠囊 999）；陰影深度統一；Icon 同一套庫、同一種線條粗細，實心只用在「已選取」等狀態切換。 |
| V-S2 | 行為一致 | 可互動元件的 Default／Hover／Active／Disabled 狀態定義清楚，處處相同。 |
| V-S3 | 文案一致 | UX Writing 用詞統一，例如「確定／確認」只選一個用到底。 |
| V-S4 | 操作邏輯一致 | 返回鍵、主要行動按鈕位置固定，不讓使用者每頁重新找（呼應 L6 Jakob's Law）。 |
| V-S5 | 元件化 | 同類元素用同一個元件（例如輸入框固定 40 或 48 高）；色彩、字體、間距、圓角存成 Tokens／Variables（原子設計：Tokens → Atoms → Molecules → Organisms）。 |

## 交件前走查清單（Unit 08 Self-Check）

版面 ＆ 排版
- [ ] 所有間距都是 4 的倍數
- [ ] 組內間距小於組間間距，沒有多餘的框線
- [ ] 全站字級控制在 5 種以內
- [ ] 內文行高在 1.4–1.6 倍之間
- [ ] 層級轉成黑白後依然清楚

色彩 ＆ 一致性
- [ ] 主按鈕與內文對比度大於 4.5:1
- [ ] 強調色只用在 CTA 與關鍵資訊
- [ ] 狀態不只靠顏色，也有 Icon 或文字
- [ ] 圓角與 Icon 風格全站統一
- [ ] 顏色與文字都已存成 Styles／Variables
