Unit 03

Shape Tools

六種形狀工具，是畫面上大多數非文字圖層的來源

矩形、線段、箭頭、橢圓、多邊形、星形——工作流程都一樣：選工具、在畫布上拖曳。差別在快捷鍵跟修飾鍵。

工具快捷鍵用途
RectangleR矩形、正方形；圓角可直接拖曳控制點調整
LineL任意方向的直線；可調描邊粗細與虛線
ArrowShift + L單向或雙向箭頭
EllipseO橢圓、正圓
Polygon / Star—邊數／角數可在右側面板的 Count 調整
拖曳時按住 Shift 畫出正方形、正圓、正多邊形；按住 Option/Alt 從中心點畫圖或縮放，兩個可以一起按。圖片、GIF、影片不是獨立圖層，是「Fill 填色」的一種，直接拖放到任何有 fill 屬性的圖層上就能加進去。

Layers

圖層面板排在上面的，畫布上就蓋在上面

一份設計是形狀、文字與其他圖層疊出來的，彼此可以互相蓋住，但還是能個別點選、編輯。圖層順序決定的是畫布上的堆疊關係，不是別的。

這張卡片有 4 個圖層：照片矩形在最下面，頭像橢圓疊在照片上，標題與副標文字疊在最上面。

Unit 03

Frame

Frame 是接下來三個功能的地基

圖層還有 Frame、Text、Component、Instance 這些類型，其中 Frame（框架）最關鍵——Auto Layout、Component、Prototype 這三個接下來要講的功能，都是以 Frame 為基礎建立的。

Frame最基礎的容器，有明確寬高。內建 iPhone、Apple Watch 等裝置尺寸預設。
Text用 Text 工具建立，內建數百款免費 Google 字體。
Shape矩形、橢圓、多邊形；Pen 工具可畫自訂線條與插畫。
等一下的 Auto Layout、Component、Prototype 三個功能，都是建立在 Frame 上的——先把這個順序記住。

Unit 03

Why Auto Layout

手動排版，內容一變全部要重排

按鈕的文字變長、清單多了一筆、畫面要換一個螢幕尺寸——這些狀況手動排版都要重新對齊一次。Auto Layout 讓 Frame 依照方向、間距、留白、對齊自動排列內容，內容變動時排版自動跟上。

按鈕文字變長手動排版：按鈕寬度沒跟著長，文字被切掉或溢出
清單多一筆手動排版：後面的項目全部要往下手動移動
換螢幕尺寸手動排版：每個尺寸都要重新排一次版

Unit 03

Toggle On

選取圖層，按 Shift + A

  1. 選取一個或多個圖層。按 Shift + A，或點右側面板 Auto Layout 旁的加號，或右鍵選 Add auto layout。
  2. Auto Layout 只作用在 Frame 上。選的是一般圖層，Figma 會自動在外面包一層 Auto Layout Frame。
  3. 選 Flow 方向。Vertical（沿 y 軸）、Horizontal（沿 x 軸，可選是否換行）、Grid（欄與列）。
批次判斷、移除 Auto Layout 這些進階快捷鍵留在講義第 4 節查，練習不會用到。

Key Properties

四組屬性決定 Auto Layout 排出來的樣子

屬性在調什麼
PaddingFrame 邊界與內容之間的空白
Gap物件與物件的距離，可固定值，也可用 Between／Around／Evenly
Alignment物件在 Frame 裡怎麼對齊
ResizingHug contents（依內容縮到最小）／Fill container（撐滿父層）／Fixed（固定尺寸）
個別物件可以開 Ignore auto layout，跳出自動排列邏輯改用絕對定位——例如浮在角落的通知紅點。

Component & Instance

改一次主元件，複本跟著同步更新

Main Component（主元件）定義這個元素的所有屬性；Instance（實體）是主元件的複本，可以重複使用在設計裡。

可以改不能改
Instance文字、填色、描邊、效果——調整成符合當下情境圖層堆疊順序（z-index）、圖層內的位置

Variants

同一顆按鈕，四種樣子收在同一個元件裡

選取多個 Component → 右側面板點 Combine as variants，Figma 會收進同一個 Component Set。屬性預設叫 Variant、Property 2……要自己重新命名成 Type、Size 這種看得懂的名字。

Unit 03

Naming

一個屬性只控制一件事，不要混在一起

✕ 一個屬性管多件事Style = Primary Large、Secondary Small……組合會越加越多，改一個尺寸要新增一堆選項
✓ 拆成獨立屬性Type（Primary／Secondary）+ Size（Large／Small），兩個屬性自由混搭，4 個組合只要 2+2 個值
命名慣例範例：Button/Primary/Large/Default/False——Component Set 是 Button，底下 Type／Size／State／Icon 各自獨立。

Unit 03

Prototype

畫面接起來，才能真的點著走一次

Design 分頁做視覺設計，Prototype 分頁設定互動，按 Shift + E 快速切換。一個檔案可以有多條 Flow——每條 Flow 是一組串起來的畫面與連接線，對應一段使用者旅程（例如註冊、結帳各是一條）。

① 建立連接選熱區，拖到目標畫面
② 設定互動Trigger／Action／動畫
③ Prototype 設定裝置外框、起始畫面
④ Preview 測試照真實使用者的方式點一次

Trigger · Action · Destination

一條連接線，三個要設定的東西

Trigger（觸發條件，如 On click）→ Action（動作，如 Navigate to）→ Destination（目的地，多數情況要是最上層 Frame）。

Connect

拖出那條連接線，再挑一種轉場

步驟做法
1切到右側 Prototype 分頁，選熱區物件
2拖曳物件邊緣的「＋」到目標 Frame，或點 Interactions 區塊的 Add
3設定 Trigger／Action／Destination
4選動畫：Push／Slide／Dissolve，或用 Smart Animate 自動轉場同名圖層

Common Blockers

練習時最常卡住的四個地方

卡住的地方原因怎麼解
Shift + A 沒反應選到的是 Group 不是圖層本身先確認選取範圍，或直接右鍵選 Add auto layout
物件撐不滿寬度Resizing 還是 Fixed，不是 Fill container選取子物件，右側面板把 Resizing 改成 Fill
Combine as variants 按了沒用選到的物件不是 Component（還是一般 Frame）先把每個版本各自變成 Component（右鍵 Create component），再合併
Prototype 連接線拉不出去目標不是最上層 Frame，或熱區選錯圖層確認目的地是獨立的頂層 Frame，熱區選外層可點的容器
